<h1 align="center">lvcc0's arch dotfiles</h1>

## software used
* sway (swaybg, swaybar, swaylock, swayidle)
* mako (might change to swaync later)
* kitty
* ly
* wmenu

## installation
```
git clone https://github.com/lvcc0/dotfiles.git
cd dotfiles

cp -r fastfetch kitty mako scripts sway wallpapers ~/.config/
sudo cp -r ly/config.ini /etc/ly/
```
